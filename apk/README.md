# apk/ - old releases

These APKs (v1.0 - v2.2) are the **historical releases from before the repair**. They contain Stockfish 11 and the
old position tracker that changed piece identities by itself. They are kept only for reference; do **not** install them.

The repaired version (v2.3, Stockfish 19) is built by `tools/build-apk.sh` + `tools/package-apk.sh`
or by the GitHub Actions workflow (see `docs/BUILDING.md`). It is not stored here because it could not be built
in the environment where the repair was done.
